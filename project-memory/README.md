# Magnolia Regional Medical Center: project memory

Everything needed to turn this class project into a portfolio piece later, without having to remember the details.

| | |
| --- | --- |
| **Project** | Magnolia Regional Medical Center, a landing page and supporting pages for a fictional Georgia hospital |
| **Designer and developer** | Ashia Ware |
| **Course** | CIST 2531 Web Graphics II |
| **Completed** | October 2026 |
| **Built with** | HTML, CSS, JavaScript, Tailwind CSS, Lucide icons, Canva Code |
| **Pages** | Landing page, Specialty care, Primary care, Diagnostic imaging, Find a doctor, Patient portal (sample preview), Project notes and sources |

## What is in this folder

| File | Use it for |
| --- | --- |
| [case-study.md](case-study.md) | The full story: goals, process, decisions and results. Start here when writing the portfolio page. |
| [brand-guide.md](brand-guide.md) | Colors, fonts, logo, imagery and interface patterns, with the reasoning behind each. |
| [design-iterations.md](design-iterations.md) | Every round of feedback and what changed, in order. Good material for a "process" section. |
| [credits.md](credits.md) | Every photo, font, library, tool and source used, with licenses. Copy these into the portfolio. |
| [tech-notes.md](tech-notes.md) | How the files fit together, how to run the site, and known limitations. |
| [portfolio-blurbs.md](portfolio-blurbs.md) | Draft text for a portfolio card, a short summary and a longer write-up. |
| `portfolio-images/` | Cropped screenshots ready to drop into a portfolio. |
| `Magnolia-Regional-Ashia-Ware-with-screenshots.zip` | The whole site plus full-page screenshots of every page, kept as an archive. |
